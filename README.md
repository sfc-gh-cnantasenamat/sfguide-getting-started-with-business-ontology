# Getting Started with Business Ontology

A Snowflake developer guide by Tianxia Jia. Build a governed Business Ontology of domains, entities, metrics, code-mapping terms, and relationships, then surface it to a Cortex Agent alongside a Semantic View.

- Guide: [`quickstart/getting-started-with-business-ontology/getting-started-with-business-ontology.md`](quickstart/getting-started-with-business-ontology/getting-started-with-business-ontology.md)
- Companion files: [getting-started-with-business-ontology](https://github.com/sfc-gh-cnantasenamat/getting-started-with-business-ontology), with the setup scripts in `sql/`.

> **Private Preview:** Business Ontology must be enabled on your Snowflake account before use.
